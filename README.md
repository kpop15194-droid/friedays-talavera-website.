# Friedays – Talavera Branch Website

A responsive website for Friedays Talavera Branch.

## Features

- Responsive website for desktop and mobile
- Menu categories and search
- Shopping cart and estimated total
- Pickup date and time selection
- Weekday and store-hour validation
- Pre-order message preparation
- Facebook Messenger handoff

## Branch Information

- Location: Near Talavera National High School, Diaz Street, Brgy. Pag-asa, Talavera, Nueva Ecija
- Hours: Monday–Friday, 9:30 AM–7:30 PM
- Student meal range: ₱49–₱69

## Menu

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Click Settings.
3. Select Pages in the left sidebar.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch.
6. Select the / (root) folder.
7. Click Save.
8. Wait for GitHub Pages to publish your website.

## Important Order Information

This version prepares the customer's order and opens the supplied Facebook link.

It does not yet:
- Automatically save incoming orders to a database.
- Automatically notify staff.
- Check live stock or availability.
- Reserve pickup slots.

A secure backend or ordering service is required for those features.

All orders must be confirmed by Friedays staff.
